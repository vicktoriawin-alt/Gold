 # 🪙 XAU/USD Тренажер (0.17 Лот | Вихід 0.36 | 42V)

Інтерактивний симулятор торгівлі золотом (XAU/USD) з ризик-менеджментом, частковою фіксацією прибутку та захистом депозиту.

🔗 **[Відкрити тренажер онлайн](https://github.io)**

## ⚙️ Короткий огляд функціоналу
* **Позиція та ризик:** Стартовий депозит $2,000, базова позиція 0.17 лоту. Ризик адаптується залежно від балансу (3.5% до 1.5%), стеля ліквідності — 5.00 лотів.
* **Алгоритм «Вихід 0.36»:** 36% обсягу фіксується на тейку 1:1.2, решта 64% утримується до тейку 1:2.2.
* **Захист 42V:** Після збиткових угод розмір лоту зменшується (×0.5, потім ×0.25), а після 3 стопів поспіль або просадки на 30% торгівля блокується.
* **Сейф:** Можливість виводити прибуток у захищений сейф.
